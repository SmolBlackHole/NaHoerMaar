# Contributing to NaHörMaar

Parent: [Project README](README.md)

Use the [development guide](docs/development.md) for setup and checks. Keep
changes focused and update the relevant documentation when behavior changes.

Before proposing a change, run `python scripts/dev.py check` and include the
results. Mention any checks you could not run.

Link to existing explanations instead of repeating them. Label planned features
as planned and check documentation links with `python scripts/repository_checks.py`.
